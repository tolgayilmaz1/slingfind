# 🎯 SLING FIND

A memory matching game where you slingshot balls to flip and match cards — with wall bounces, combos, and global hi-scores.

**[▶ Play Now](https://YOUR_USERNAME.github.io/sling-find)**

---

## 🕹️ How to Play

- **Drag** the slingshot and release to shoot
- **Hit a card** to flip it open
- **Match two identical cards** to score
- **Wall bounces = combo multiplier** (1 wall = 2×, 2 walls = 4×, 3 walls = 6×)
- **Combo bonus** → extra balls fly to your counter
- **Remaining balls** at level end = bonus points (+10 each)

## 🌍 Languages

Turkish 🇹🇷 / English 🇬🇧 — select on the start screen

## 🏆 Hi-Scores

Global leaderboard powered by Firebase Realtime Database. Enter your name on the start screen — scores are saved across all players worldwide.

## 🚀 Deploy

This is a single `index.html` file. Host anywhere:
- **GitHub Pages** — free, just enable in repo Settings → Pages → main branch
- **Netlify** — drag and drop the file
- **Firebase Hosting** — `firebase deploy`

## 🛠️ Built With

- Vanilla JS + HTML5 Canvas
- Web Audio API (procedural sound effects)
- Firebase Realtime Database (global hi-scores)
